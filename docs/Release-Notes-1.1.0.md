## What a reviewer should know

Nothing about the app's offline nature changed: there is still no networking, no analytics and no
account. The new signature is produced on the device from the wallet's own seed, covers one fixed
public sentence (`OwnbitAuth:v2:epoch=1`) with no amounts or recipients in it, and is stored
beside the wallet's existing public key cache. A wallet created by 1.0.0 shows a one-time password
prompt on the Wallet Level pairing page before its code can be produced; chain-specific codes
(Coin Level) are unchanged and need no password.

1.1.0 also signs any EVM chain ID (60 are named), EIP-7702 authorizations and Solana v0 transactions
with address lookup tables. The parts an offline device cannot read (lookup-table accounts, the delegate
contract's code, the fee level on an unreferenced chain) are marked as such, never guessed, and a lookup
table or a delegation always needs explicit confirmation. Still no networking.
